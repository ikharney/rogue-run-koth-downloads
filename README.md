## Install
1. Download the ZIP and extract the entire archive.
2. Run Install KOTH.cmd and complete required prerequisite installation.
3. Launch Play KOTH. Online rooms require your own Epic Games account.
4. Both players must use the same version. Create a room or join using the host's room code.

This is an unsigned Windows 64-bit development playtest. Epic sign-in, room creation and local host match startup have been checked. Remote joining and full multiplayer testing remain in progress.

The 19 November 2026 package contains the October 29 gameplay binaries with the new Proxigo EOS configuration. It is not a new gameplay build.
